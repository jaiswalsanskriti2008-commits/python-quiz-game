
# 🎮 Python Quiz Game

## 📌 Project Description
This is a simple and interactive Quiz Game developed using Python. It asks users multiple-choice questions and checks their answers. At the end of the quiz, it displays the total number of correct and wrong answers along with the final score.

## ✨ Features
- Displays 5 multiple-choice questions.
- Provides 4 options (A, B, C, D) for each question.
- Accepts user answers through keyboard input.
- Checks whether the answers are correct or wrong.
- Displays the correct answer for incorrect responses.
- Calculates the final score.
- Displays a performance message based on the score.

## 🛠️ Technologies Used
- Python 3
- Lists
- Dictionaries
- For Loops
- If-Else Statements
- User Input and Output

## ▶️ How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python editor.
4. Run the following command in the terminal:

```bash
python quiz_game.py
```
